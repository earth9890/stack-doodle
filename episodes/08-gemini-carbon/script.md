# chapter: Argon, then Carbon
# pic: Argon, then Carbon, two weeks apart
Carbon arrived just two weeks after Gemini four Argon, the model Google rolled out to everyone in October. //
# pic: argon = lazy; carbon bonds with everything
Fun naming fact: argon comes from the Greek word for lazy, because it refuses to react with anything. / Carbon forms more compounds than every other element combined. [J] //
# pic: long horizon
Long-horizon means it keeps working on one hard problem for a very long time. / Google says that inside its own teams, Carbon ran for days, / root-causing and patching subtle bugs across large codebases. //
# pic: Dev gives up after one stand-up
Days. Most of us lose interest in a bug after one stand-up meeting. [J] //
# chapter: Find, prove, fix
# pic: the home inspector
Here's the easiest way to picture it. / Think of a home inspector who doesn't just write crack in wall on a clipboard. //
# pic: finds it, leans on it, fills it
This one finds the crack, leans on the wall to prove it really moves, / and then fills the crack before you get home. [J] //
# pic: find / prove / fix with the vendor's numbers growing
Step one, find. Google says Carbon scores eighty-eight point two percent on SEC-bench Pro, / a test of discovering real vulnerabilities in real software. //
Step two, prove. On ExploitGym, which checks whether a found bug can become a working exploit, / Google reports fifty-four point eight percent. //
Step three, fix. On CWE-bench, which turns a confirmed flaw into a working patch, Google says seventy-one percent. //
# pic: Chrome team, 10x better patches than an unnamed lab
And Google says its Chrome team saw Carbon make high-quality patches more than ten times better / than another lab's large frontier model, which Google very politely did not name. [J] //
# pic: Artificial Analysis index
On general smarts, the independent Artificial Analysis Intelligence Index puts Carbon first at fifty-nine, / one point ahead of Claude Opus five point five, and two ahead of G P T six Astra. //
# pic: photo finish
One point. Frontier A I is now a sport decided by photo finish. [J] //
# chapter: Why it's locked
# pic: good news / bad news
Which brings us to the gate. The good news is that Carbon is state-of-the-art at writing exploits. / The bad news is that Carbon is state-of-the-art at writing exploits. [J] //
# pic: one key, two doors; a prompt has no badge
The skill that proves a bug is dangerous is exactly the skill an attacker needs. / And a prompt doesn't come with a badge. [J] //
# pic: a deliberate approach, US pre-release testing
So Google says it's taking a deliberate approach, / and that Carbon is in the U S government's voluntary pre-release testing process. //
# pic: Fairwind, 650+ partners
Access goes through Google's Fairwind Program. / According to Forbes, it works with more than six hundred fifty partners, / with governments, critical infrastructure and core tech platforms first in line. //
# pic: the rules
Partners get background checks, must use phishing-resistant multi-factor login, / and can use Carbon for pen testing and malware analysis, but not for building malware. //
# pic: the dress code
It's a nightclub where the dress code is two-factor authentication. [J] //
# chapter: Claims vs reality
# pic: guardrails off
One footnote matters here. Google says it ran the outside cyber benchmarks without guardrails, / so those scores describe the model with its refusals switched off. //
# pic: not reproduced
And nearly all the cyber numbers come from Google's own testing, / with no independent reproduction yet, as Forbes points out. //
# pic: vendor claim, 2x fewer unsupported claims
Google also says Carbon cuts unsupported claims roughly in half compared to Argon. //
# pic: independent accuracy
Artificial Analysis measured something more interesting. / On its knowledge test, Carbon answers more questions correctly than Argon, fifty-eight percent versus forty-eight. //
# pic: hallucination rate went up
But its hallucination rate went up too, from four percent to eleven. / It knows more, and it's more confident about the things it doesn't. [J] //
# pic: still #1 on that test
To be fair, it still tops that whole test. Fifty-four points, the best of any model they've measured. //
# pic: behind Opus at programming
And Artificial Analysis says it's still behind Claude Opus five point five at programming. / So the best model in the world is not the best model at everything. [J] //
# chapter: The price of a locked door
# pic: the price
Google even published a price: two dollars per million input tokens and ten per million output, the same as Argon, / rising to four and twenty after an introductory period with no announced end date. //
# pic: an introductory price for a model you can't buy
So there's an introductory price for a model you can't buy yet. [J] //
# pic: Anthropic did it first

# chapter: The catch
# pic: the part the launch post skips
But here's the part the launch post skips. / A model that finds bugs faster than your team can review them doesn't remove the bottleneck. / As Forbes puts it, it moves the bottleneck to triage, the humans who confirm and ship each fix. //
# pic: the gate's holes
And the gate has holes of its own. / A WorkOS analysis, cited by Forbes, says the vetting is a one-time check, / access goes to companies while misuse comes from individual people, / and the partner list is private, so no partner knows who else is inside. //
