## Description
PHP2Shell explained: two critical PHP vulnerabilities (CVE-2026-109618 and CVE-2026-109619) can let attackers run code on unpatched PHP servers. Here's what broke and exactly what to update.

PHP runs about 70% of websites. The fixed releases are PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 (21 Oct 2026). Update the PHP runtime, then restart Apache, PHP-FPM and any long-running PHP workers. Updating WordPress alone does not update the PHP underneath it. On a Linux distro, check your package version: distros keep the old version number with the fix backported.
