## Checked and NOT used
- "Copilot Standalone $10/user/month for anyone": wrong scope. It is for users inside an enterprise account without a GHE license (the script says so).
- Session continuity / HydraFusion history, GitHub intelligence, AI scan, Replica details: real, but cut for length (Replica is only named in the jargon list).
- The Fusion 30 % limited-time discount: true, but it would muddy the "billed at standard rate" line. It is mentioned in package.md description context only if needed.
- Press roundups (dev.to, smartscope.blog, cryptobriefing, remio.ai) from the parent's search: consistent with the primary pages, not cited. WebSearch/WebFetch were rate-limited during this build, so no independent benchmark of Fusion or Max was found. The script labels both as GitHub's numbers.

## Contested / hedged
- Fusion "about half the cost": per task, against one competitor setup, on a third-party index *as reported by GitHub*. Said as "GitHub says".
- Max "highest F1 on ReviewBench": GitHub's claim, explicitly "we haven't tested it".
- "the most relatable reason this exists" is our framing of AT&T's customer quote, not GitHub's stated rationale.
